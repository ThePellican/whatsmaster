# WhatsMaster

Reconstrução visual, no formato do WhatsApp Web, das conversas transcritas na **IPJ-A nº 3298613/2026** da Polícia Federal (Operação Compliance Zero). Ponto de vista: celular apreendido de Daniel Bueno Vorcaro.

Não é o aplicativo original. Mensagens de visualização única abrem o texto da nota recuperado pela perícia. O gabinete do ministro Alexandre de Moraes contestou, em março de 2026, que o número salvo como “Alexandre de Moraes BRASILIA” fosse o dele.

Abrir `index.html` no navegador, ou a página publicada no GitHub Pages.

Fotos públicas: Wikimedia Commons (créditos em `FONTES.txt`). Funcionários sem foto pública usam iniciais.
